# 美漫斜切拼接封面

用粗黑、不等宽的斜切分镜和美漫墨线，制作自媒体视频、图文或宣传海报的封面。参考《AI 产品怎么选？》的拼接语言，按本次内容安排人物、场景、主体与文字，不把中央标题牌固定为所有任务的模板。

## 准备什么

提供主题、目标观众、确认的主副标题、需要的比例，以及本人或已获授权的人物照片。已有系列版式、品牌标识或认可底图时一并提供。需要可用的图像生成或编辑工具、独立文字排版工具及获授权的字体；本仓库不附带这些服务、素材或账号。

## 安装与使用

下载或克隆完整仓库，保留 `SKILL.md` 与 `agents/openai.yaml`，将 `produce-comic-panel-cover` 文件夹放入所用工具的 Skills 目录。Codex 的常用位置是 `~/.codex/skills/`；已有同名安装时，先检查并保留自己的改动。

```text
使用 $produce-comic-panel-cover，为【主题】做一张【3:4】封面。
面向【观众】，标题为【完整标题】，使用我提供的授权照片。
沿用已确认的系列版式；若是独立海报，先规划标题区和主体保护区，
不要让文字、色牌或分格线切开人物动作和关键物件。
```

入口与制作要求见 [SKILL.md](SKILL.md)。已有系列可沿用中央牌；独立海报按主体选顶栏、侧栏或干净文字区。文字与品牌标识单独准确排版，保护完整词组和自然字形。各比例分别构图，交付成图与必要的可编辑源，并检查实际导出及手机缩略图。

## 视觉参考与边界

[《AI 产品怎么选？》已选竖版](https://github.com/xupengli406-del/edit-multi-person-interview-video/blob/main/examples/ai-products/cover-3x4.png)可用于观察分镜与墨线。示例中的人物、产品、颜色和位置不作为下一张的固定值；漫画成图也不能替代真实身份参考。

输入素材、字体、品牌标识与外部服务按各自授权使用。本仓库不附带原始人物照片，也不承诺点击率或传播效果。

## 实际案例：AI Native 新时代列车（完整海报）

![AI Native 新时代列车完整海报](examples/poster.png)

- **实际输入**：以“AI Native 新时代列车”为主题，将品牌、教程与 Skill 分类、会员权益、资历及用户确认的服务与联系文案编排为完整宣传海报。
- **视觉与版面**：独立顶栏承接品牌与主题，人物和完整列车由粗黑斜切分镜拼接；下方用漫画色块与边线组织教程、分类、权益和行动信息。
- **实际输出与检查**：此处展示1080×1440的整张定稿，主视觉、标题、详情、服务条件与行动入口均包含在同一张图中。已查看完整成图，核对标题与关键主体的间隔、各组信息归属以及底部行动区的完整性。案例中的具体文案、人物、数量和模块只对应本次任务，后续按实际需求重排。
